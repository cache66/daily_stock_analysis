# 主策略总纲：围绕“逻辑 + 资金 + 趋势 + 业绩兑现”做一切

这份文档用于固定当前项目后续的主策略方向。

以后无论新增脚本、补字段、做快照、接 `/signals`、还是调整排序逻辑，都优先回答一个问题：

`这项改动，是在帮助我们更稳定地找到“有逻辑、有资金、有趋势、并且最终能兑现到业绩”的股票吗？`

如果不是，优先级就要往后放。

## 1. 主目标

我们要找的，不是单纯“涨得快”的股票，而是更偏下面这一类：

- 趋势已经走出来，至少不是逆势乱拉
- 背后有能讲得通的产业逻辑、业绩逻辑、涨价逻辑或周期逻辑
- 市场资金对这套逻辑已经形成一定共识
- 这种逻辑不是纯情绪叙事，而是有机会兑现到财报、订单、价格、利润或市占率

一句话概括：

`先看逻辑是否成立，再看资金是否认可，再看趋势是否确认，最后看业绩是否能兑现。`

## 2. 主判断框架

后续所有策略，尽量往这 4 层主框架里挂：

### 2.1 趋势层

解决的问题：

- 图形是不是已经走好
- 月线、周线、日线是不是处于顺势结构
- 是真正的强趋势，还是反抽、脉冲、骗线

当前已对应的本地能力：

- `hundred_day_high`
- `monthly_slow_rise`
- 通用 K 线筛选

这层更像：

- 入场前提
- 结构过滤器
- “不和烂图形浪费时间”的第一道门槛

### 2.2 逻辑层

解决的问题：

- 这只票为什么涨
- 这个上涨有没有产业、业绩、产品、价格、周期上的支撑
- 它属于主线核心、跟风、映射，还是伪逻辑

优先看的逻辑来源：

- 业绩超预期
- 业绩质量改善
- 商品涨价传导
- 周期反转或周期扩张
- 主题核心映射
- 产业链位置和受益方向

这层是未来的核心，不是附属说明。

### 2.3 资金层

解决的问题：

- 市场是不是也在相信这套逻辑
- 资金是在集中，还是分歧
- 是短线情绪试错，还是主线资金抱团

我们后续要重点补强的，就是这一层。

当前统一入口文档：

- `docs/CAPITAL_PROFILE_STRATEGY.md`

资金层建议长期拆成几块：

- 辨识度
- 板块地位
- 相对强度
- 成交额和流动性
- 连续性
- 主动性
- 联动性

当前已经开始沉淀为统一字段的，是：

- `capital_consensus_score`
- `capital_profile_score`
- `capital_flow_score`
- `relative_strength_score`
- `liquidity_score`
- `main_net_inflow / inflow_5d / inflow_10d`

这套字段当前已经先接到：

- `earnings_surprise`
- `monthly_slow_rise`

一句话说，逻辑再好，如果没有资金承接，通常只能算“研究对象”，还不算“主策略对象”。

### 2.4 兑现层

解决的问题：

- 这套逻辑能不能兑现到财报或经营结果
- 是短期故事，还是能逐步变成利润
- 是一次性刺激，还是阶段性景气

这一层和“逻辑层”关系很近，但不是一回事：

- 逻辑层偏“为什么可能涨”
- 兑现层偏“为什么这不是空话”

当前最接近这层的，就是：

- `earnings_surprise`
- `earnings_quality`
- 涨价传导里的财报验证

## 3. 主排序原则

以后做综合排序时，建议统一采用下面的优先级：

1. 先排除没有趋势、没有逻辑、没有兑现基础的票
2. 在剩余票里，优先“逻辑强 + 资金强 + 趋势强”
3. 再区分它是“已经兑现”还是“正在兑现”
4. 最后才看弹性、估值、节奏和交易型细节

简单说就是：

`先看对不对，再看强不强，最后才看快不快。`

## 4. 当前最接近主策略的几条线

按这个总纲看，当前仓库里最有价值的几条线分别补的是：

| 主线 | 当前作用 | 在总框架中的位置 |
| --- | --- | --- |
| `hundred_day_high` | 找已经走出趋势确认的票 | 趋势层 |
| `monthly_slow_rise` | 找中期结构漂亮、月线顺滑的票 | 趋势层 |
| `earnings_surprise` | 找能被财报和公告验证的业绩逻辑 | 逻辑层 + 兑现层 |
| `earnings_quality` | 找“不是假增长”的业绩质量 | 兑现层 |
| `dragon_head_candidate` | 找资金和辨识度更集中的核心票 | 资金层 |
| `commodity_price_pass_through` | 找涨价、周期、产业链传导逻辑 | 逻辑层 |
| `theme_core_mapper` | 找题材里的真核心和假核心 | 逻辑层 + 资金层辅助 |

所以后面最理想的组合，不是单看某一条线，而是看叠加。

## 5. 最值得长期维护的组合

后续一切都围绕下面这几类“组合命中”去做，会比单线更接近你的目标。

### 5.1 新高趋势 + 业绩确认

适合找：

- 走势已经强
- 业绩也在跟上
- 不是纯情绪硬拉

当前对应：

- `hundred_day_high`
- `earnings_surprise`
- `hundred_day_high_with_earnings`

### 5.2 月线漂亮 + 周期改善 + 业绩逐步兑现

适合找：

- 不是爆发式妖股
- 而是中期慢趋势
- 行业景气或价格上行开始逐步兑现到业绩

当前对应：

- `monthly_slow_rise`
- `commodity_price_pass_through`
- `earnings_quality`

### 5.3 逻辑清晰 + 资金集中 + 板块核心

适合找：

- 市场已经形成主线共识
- 逻辑和资金互相强化
- 个股不是边缘映射，而是核心承载

当前对应：

- `dragon_head_candidate`
- `theme_core_mapper`
- 板块辨识度快照

## 6. 明确不作为主目标的方向

以下类型不作为长期主轴，只能当辅助观察：

- 纯消息刺激但没有后续兑现路径的票
- 只有短线情绪，没有板块共识和资金连续性的票
- 图形很差，只靠一句故事支撑的票
- 业绩看起来增长，但质量很差、现金流差、周期走坏的票
- 只有低位、便宜、补涨预期，但没有主逻辑和主资金的票

## 7. 以后新增策略时的落地要求

以后新增一个策略、字段、脚本或快照，尽量都补一句“它属于哪一层”。

建议统一写成下面这种方式：

- 这个能力主要补 `趋势层`
- 这个能力主要补 `逻辑层`
- 这个能力主要补 `资金层`
- 这个能力主要补 `兑现层`
- 这个能力主要服务“组合交叉验证”

如果一个能力说不清属于哪层，通常就说明它离主策略太远了。

## 8. 后续开发优先级

如果以后所有工作都围绕这条主线，建议优先顺序如下：

1. 补“资金层”的结构化字段和排序
2. 做“趋势 + 逻辑 + 资金 + 兑现”的综合评分框架
3. 把组合信号快照化、可回看、可复盘
4. 在 `/signals` 里把多条主线做交叉视图
5. 再去补更细的行业、周期、价格、事件催化专题

## 9. 一句总原则

后续的核心不是“做更多策略”，而是：

`把已有策略都收敛到同一条主线上，让它们一起回答：这只股票的上涨，到底有没有逻辑、有没资金、趋势强不强、最后能不能兑现。`
