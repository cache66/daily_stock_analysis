## 当前阶段

阶段：`骨架已完成，进入单机外部进程接法准备阶段`

当前定位：

- 这不是一条已经接入真实短线引擎的策略链路
- 这是当前工程里的独立短线编排骨架

## 当前范围

当前范围只包括：

- 独立代码目录
- 独立 CLI 入口
- `WonderTrader` stub 候选输入
- `FinGenius` stub 解释输出
- 单机 `process mode` 外部脚本接法
- 仓库内桥接模板脚本
- 统一聚合结果
- Markdown / JSON 产物

## 当前非目标

当前不包括：

- 真 `WonderTrader` 业务逻辑接入
- 真 `FinGenius` agent 业务逻辑接入
- 实盘执行
- 盘中实时服务
- 当前四条主策略的主链路改造
