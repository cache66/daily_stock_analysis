# 个人策略文档说明

这组文档只服务我个人在本仓库里的三类内容：

- 个人策略目录与默认口径
- 个人复盘与修改留痕
- 个人本机运行环境说明

组织个人投研先看[《个人投研工作台重构方案》§0](./个人投研工作台重构方案.md#0-先看这一页三层找机会)：热点雷达发现驱动、盘后复盘检查短线与长线变化、长期研究积累公司/行业/ETF认知，共用市场环境和机会清单。§2.2~§2.4 把个人策略、十个筛选预设、分析 skill 分开，列现有执行入口；§1/§7.1 说明主工程及外部开源能力怎样复用。当前是方案，首交 A1-a 零人工只读总览，缺来源明示；冻结策略与 RE01 接入限制保持，不要求每天翻本目录或逐票填记录。

后续增加策略、数据或功能，查[方案 §7.2~§7.4](./个人投研工作台重构方案.md#72-扩展边界业务入口稳定按类型接入)的接入边界、公共结果合同与验收流程；复用现有入口，以第二类接入验扩展性，尚未实现统一插件系统。首版缺材料的分区折叠提示，两类来源健康批次才验收，不以新增文件数或候选数量充完成度。

先看 [`个人策略协同总纲.md`](./个人策略协同总纲.md)：它是市场感知、短期/长期研究、历史经验和量化验证的架构入口。后续能力先按总纲分类，再进入下列资产、参数和专题文档；总纲中“规划中”不代表已经实现或验证有效。

研究单只股票先读总纲 §2.8 的分层入口，再读 [`单票卡规格-v0.1.md`](./单票卡规格-v0.1.md) 与 [`单票卡数据可行性矩阵.md`](./单票卡数据可行性矩阵.md)。L0 短期、L1 财务、L2 多源按任务分别准入，不等 22 槽全绿；五票行情已修复，首批 L0 生成 5 张，技术观察数据通过 4 张、工行复权事件受限 1 张，事件研究待核，均无交易权限。A2 的 20 只只验合同和判读，长期增量另用全市场 PIT 面板；§5 关 3 仍为人工复核，首批卡尚未接入自动服务。

当前第四轮入口：[规则登记表](./单票卡规则登记表.md)及[阳光电源×中期选举事件卡](../../data/strategy_review/single_stock_cards/20261107_event_r4/300274_us_midterm_2026.md)。配置与事件研究资格分开，状态仅作描述；纵向核验已完成，个股资格未通过，规则晚于事件、不称事前成功。旧r3产物保留；详细缺口见矩阵§7。
