# 个人策略中英对照表

> 说明：这组文档只服务我个人在本仓库里的本地策略、个人复盘和个人运行习惯，不属于原工程通用文档。

最后更新：2026-07-09  
真源优先级：代码与脚本 > 本文档

这份文档只做一件事：把仓库里常见的本地策略英文名，整理成你日常更容易记的中文叫法。

如果你只想先记住最常用的几条，优先看这 6 个：

| 英文名 | 中文建议称呼 | 角色 | 可独立运行 | 当前是否进默认每日复盘 |
| --- | --- | --- | --- | --- |
| `trend_leader_unified` | 趋势龙头统一策略 | 补充观察 | 是 | 否 |
| `earnings_surprise` | 业绩超预期策略 | 主策略 | 是 | 是 |
| `hundred_day_high` | 百日新高策略 | 主策略 | 是 | 是 |
| `daily_slow_rise` | 日线慢涨策略 | 图形扩展 | 是 | 是 |
| `long_base_release` | 长横盘释放策略 | 图形扩展 | 是 | 是 |
| `monthly_slow_rise` | 月线慢涨策略 | 低频扩展 | 是 | 否 |

## 1. 主策略与扩展策略

| 英文名 | 中文建议称呼 | 一句话说明 | 主要入口 |
| --- | --- | --- | --- |
| `trend_leader_unified` | 趋势龙头统一策略 | 以龙头、趋势、资金、业绩兑现为主骨架的综合主策略。 | `scripts/select_trend_leader_candidates.py` |
| `earnings_surprise` | 业绩超预期策略 | 以财报、预告、快报为核心的业绩事件驱动筛选。 | `scripts/select_earnings_surprise_candidates.py` |
| `hundred_day_high` | 百日新高策略 | 从新高突破、强趋势图形里找强势样本。 | `scripts/select_hundred_day_high_candidates.py` |
| `daily_slow_rise` | 日线慢涨策略 | 找“前面横住、后面 30-45 度慢涨”或整体缓升的图形。 | `scripts/select_daily_slow_rise_candidates.py` |
| `long_base_release` | 长横盘释放策略 | 找长时间横盘后慢推或突破释放的样本。 | `scripts/select_long_base_release_candidates.py` |
| `monthly_slow_rise` | 月线慢涨策略 | 偏中期、周月级别的慢牛结构池。 | `scripts/select_monthly_slow_rise_candidates.py` |

## 4. 容易看混的几个名字

| 容易混的英文名 | 中文理解 |
| --- | --- |
| `trend_leader` / `trend_leader_unified` | `trend_leader` 更像 fast review 里的入口别名，真正落库和核心策略名是 `trend_leader_unified`。 |
| `earnings` / `earnings_surprise` | `earnings` 是聚合入口里的简称，真正策略名是 `earnings_surprise`。 |
| `theme_core_mapper` / `theme_core_candidate_scan` / `theme_core_board_scan` | 这一组都属于“题材核心”家族，只是一个偏映射、一个偏候选、一个偏板块视角。 |
| `dragon_head_candidate` / `dragon_head_strategy` / `dragon_head_snapshots` | 一个偏扫描入口，一个偏专题说明，一个偏按日快照。 |
| `daily_slow_rise` / `monthly_slow_rise` | 一个是日线级慢涨，一个是月线级慢涨，不是同一条策略的不同参数。 |

## 5. 当前默认每日复盘到底跑哪些

按当前 [`config/local_strategy_profile.json`](../config/local_strategy_profile.json) 默认值，`run_fast_review_bundle.py` 的 `include_signals` 目前包含：

- `earnings` -> `earnings_surprise`
- `hundred_day_high`
- `daily_slow_rise`
- `long_base_release`

也就是说，当前默认每日复盘现在固定收口为 4 条，优先服务“图形 + 业绩”。

`trend_leader_unified` 仍然保留，但当前更适合当作可选补充观察，不再默认主导首页。

`monthly_slow_rise` 仍然更适合低频单跑，不在当前默认每日链路里。

## 6. 哪些不算“独立个人策略”

下面这些更像工具，不建议和主策略混在一起记：

- `scripts/select_kline_candidates.py`
  - 通用 K 线筛选器，不是一条固定命名的个人主策略。
- 各类 `snapshots` 脚本
  - 主要负责按日留档、回看、统计，不等于独立选股逻辑。
- 各类 `ranking` / `mapper` / `registry`
  - 更偏专题研究、观察池维护或读层辅助。

## 7. 推荐记忆顺序

如果你以后只想用中文快速对应，建议按这个顺序记：

1. 三条老主策略：趋势龙头、业绩超预期、百日新高。
2. 两条图形扩展：日线慢涨、长横盘释放。
3. 一条低频扩展：月线慢涨。
4. 其余都先当作观察池、专题工具或快照工具看。
