## How To Use This Log

这份文档是“详细变更与证据库”，默认按日期倒序记录，适合回答下面几类问题：

1. 某次策略改动到底改了什么；
2. 当时跑了哪些验证命令；
3. 有哪些真实实跑产物、耗时和结果；
4. 风险、边界和回滚思路当时是怎么判断的。

与其他三份文档的分工固定为：

- 当前策略资产入口与阅读导航：[`docs/LOCAL_STRATEGY_CATALOG.md`](./LOCAL_STRATEGY_CATALOG.md)
- 当前默认参数与基线口径：[`docs/LOCAL_STRATEGY_BASELINE.md`](./LOCAL_STRATEGY_BASELINE.md)
- 用户可见变化扁平摘要：[`docs/CHANGELOG.md`](./CHANGELOG.md)

维护约定：

- 这里保留细节，不追求短；
- 如果改动影响默认口径，同步更新 `LOCAL_STRATEGY_BASELINE.md`；
- 如果改动影响入口、信号清单或阅读路径，同步更新 `LOCAL_STRATEGY_CATALOG.md`；
- 如果改动是用户可见行为变化，同步在 `CHANGELOG.md` 的 `[Unreleased]` 追加单行条目。

## 记录规范（默认要求）

- 每次“新增或修改”都应在本文件按日期追加记录，禁止只改代码不留痕。
- 本地策略相关改动（`select_*` / `collect_*` / `signal_type` / 策略排序与参数）至少补齐以下字段：
  - `范围（Scope）`
  - `原因（Why）`
  - `改动（Changes）`
  - `备注（Notes）`（需说明 `README.md` 是否同步以及原因）
- 若改动是用户可见或策略行为变化，需同步在 `docs/CHANGELOG.md` 的 `[Unreleased]` 追加扁平条目。

## 2026-07-09 共享扫描 history_fetch_failed 收敛

- Scope:
  - `src/services/kline_selector_service.py`
  - `data_provider/base.py`
  - `tests/test_kline_selector_service.py`
  - `tests/test_fetcher_logging.py`
  - `docs/LOCAL_STRATEGY_BASELINE.md`

  - `docs/CHANGELOG.md`
- Why:
  - 用户反馈 `monthly_slow_rise` 以及其他本地策略存在大量 `history_fetch_failed`。
  - 排查后确认有两类公共根因：
    - shared scan shell 按 `stock_basic` 合并名称时，会把缺失值误写成字面量 `"nan"`，导致应被 `ST/PT` 过滤挡掉的历史壳/风险票漏进样本池。
    - `DataFetcherManager.get_daily_data(...)` 对自动 `days` 请求的次新股部分缓存场景处理过严：当仅“补上市前历史”失败时，会直接抛 `history fetch failed`，而不是把现有缓存回传给上层判 `insufficient_history`。
- What changed:
  - `src/services/kline_selector_service.py`
    - 收紧 `_safe_text(...)`，不再把 `NaN/None/<NA>` 变成字面量字符串。
    - `prepare_scan_universe(...)` 现在会优先基于本地 `stock_basic` 活跃代码集收口 universe。
    - shared scan 继续做 `ST/*ST/PT` 过滤，并额外挡掉明显退市名。
    - 当 service 使用自定义 `universe_provider`（例如测试或人工注入样本）时，不再强制套用活跃代码白名单，避免把外部显式提供的最小样本也误过滤掉。
  - `data_provider/base.py`
    - 当 `days` 请求命中“已有部分缓存，但补上市前 head 历史失败”的场景时，改为保留已有缓存继续返回，source 标记为 `disk_cache_partial_history:*`，让上层自然落到 `insufficient_history`。
  - `scripts/select_monthly_slow_rise_candidates.py`
    - 后置 `capital_profile` 补充现在会优先复用共享 scan shell 里已拿到的 `latest_price / pct_change / turnover_rate / total_mv` quote snapshot，减少筛选完成后额外触发 `get_realtime_quote(...)`。
