# 个人策略界面策略清单

> 说明：本文档记录 Web 个人策略矩阵第一版展示的策略名称、当前作用和主要判断逻辑。真实阈值与最终筛选结果以对应脚本、服务和复盘产物为准。

最后更新：2026-07-11

## 1. 第一版界面定位

入口：`apps/dsa-web` 的 `/personal-strategies`

数据源：

- 页面 API：`GET /api/v1/signals/personal-strategy-matrix?snapshot_date=<YYYY-MM-DD>&code=<stock-code>`
- 底层复盘读层：`GET /api/v1/signals/fast-review-stock-overview?snapshot_date=<YYYY-MM-DD>&code=<stock-code>`
- 文件：`data/manual_runs/**/<snapshot_date>/review/fast_review_stock_overview.csv`
- 后端策略 registry：`src/services/personal_strategy_matrix_service.py`
- 推荐生成入口：`python scripts/run_personal_strategy_matrix.py --snapshot-date <YYYY-MM-DD>`

第一版页面只做读层展示：

- 顶部先列策略过滤器，并显示每个策略当前命中的股票数；
- 点击策略后，下方只显示命中该策略的股票；
- 股票列表按 `短线主升 / 长线发现 / 其他观察 / 全部` 分视图展示；
- 股票列表只展示命中的策略，不再把所有未命中策略铺满卡片；
- 点击股票行可直接行内下拉展开详情，不再使用右侧抽屉，查看股票快照、命中策略说明、图形/业绩/上下文证据和原始信号键；
- 页面会基于复盘产物里已有的 `priority / 业绩质量 / 图形质检 / 相对强度 / 当日表现 / 共振数` 做一层阅读提示，但不再用它默认隐藏股票；
- 首次加载会请求 `snapshot_date=latest`，后端自动回落到最新已有 `fast_review_stock_overview.csv` 的交易日，避免周末/节假日默认到无产物自然日；
- 策略说明按分组折叠；
- 页面不重新计算策略阈值，不补行情，不补财报。

相关关系图：

- [`个人策略界面接口关系图.md`](./个人策略界面接口关系图.md)

命中判断口径：

- 读取单票行里的 `triggered_strategies / signal_keys / signal_types`；
- 后端 registry 如果发现字段中包含策略别名，或包含 `别名__专题` 这种派生信号，就认为该策略命中；
- 例如 `commodity_beneficiary__memory` 会归到 `涨价传导 commodity_price_pass_through`。

视图分类口径：

- `短线主升`：命中 `hundred_day_high / trend_leader_unified / shortline_hub / dragon_head_candidate`，用于优先看当下强度、突破和短线资金确认。
- `长线发现`：命中 `daily_slow_rise / long_base_release / monthly_slow_rise / continuous_up_* / earnings_observation / earnings_surprise` 且没有短线主升信号，用于沉淀形态、业绩和观察池线索。
- `其他观察`：专题或工具类信号，先作为辅助观察。

## 2. 当前策略清单

| 分组 | 策略名称 | 前端短名 | 当前模式 | 当前作用 | 主要判断逻辑 |
| --- | --- | --- | --- | --- | --- |
| 日复盘默认信号 | `earnings_surprise` | 业绩 | 默认日复盘 | 先筛出业绩明显改善或超预期的股票，作为“业绩好”这一维证据。 | 读取业绩快照、公告与财务指标，重点看营收/净利同比、ROE、盈利质量、报告期与机构预期；命中后仍需要结合板块、位置和想象空间二次判断。 |
| 日复盘默认信号 | `hundred_day_high` | 新高 | 默认日复盘 | 识别价格已经摆脱中期平台、市场开始给出强度确认的股票。 | 基于最近交易日是否接近或突破百日高点，并结合涨幅、回撤和流动性做基础过滤；适合和业绩、题材共振一起看。 |
| 日复盘默认信号 | `daily_slow_rise` | 慢涨 | 默认日复盘 | 寻找近阶段阳线多、走势没有明显走差、缓慢抬升的图形。 | 当前默认使用 `review_balanced` 画像，适度放宽回撤和单日涨幅限制，同时用近 `10` 日回撤护栏挡掉近期明显破位的样本；这是纯图形观察的核心入口。 |
| 日复盘默认信号 | `long_base_release` | 平台 | 默认日复盘 | 找长期横盘后开始放量/突破的结构，偏“底部平台被资金重新定价”。 | 当前使用 `loose` 画像，关注长周期压缩、平台区间、近期放量与突破关系；命中后要继续看行业估值、板块风口和个股辨识度。 |
| 趋势与纯图形观察 | `trend_leader_unified` | 趋势 | 非默认扫描 | 寻找阶段涨幅、强度和流动性都靠前的趋势股。 | 以 60 日涨幅、换手率、相对强度、行业共振和风险过滤做预筛；当前不在默认日复盘信号集合里，更多用于专题扫描或候选池补充。 |
| 趋势与纯图形观察 | `monthly_slow_rise` | 月慢 | 非默认扫描 | 从更长周期确认慢牛或长趋势，不追求短期爆发。 | 按月线/长周期结构看上涨连续性、回撤、均线与平台抬升；适合辅助判断“位置是否舒服”，不适合单独作为短线买点。 |
| 趋势与纯图形观察 | `continuous_up_ratio` | 阳线 | 非默认扫描 | 量化最近一段时间阳线占比，过滤阴跌或走势松散的图形。 | 统计近 N 日上涨日比例、区间涨幅和回撤，强调“阳线多、占比大、最近没有走差”；可作为纯图形票的加分项。 |
| 趋势与纯图形观察 | `continuous_up_streak` | 连涨 | 非默认扫描 | 识别短期连续上涨段，用来观察强势延续或过热风险。 | 统计连续上涨天数、涨幅和回撤风险；更适合做短线强度提示，不适合替代板块和基本面判断。 |
| 业绩观察 | `earnings_observation` | 业观 | 观察池工具 | 对业绩出来后表现不错的股票持续跟踪，而不是只在公告当天看一次。 | 维护观察池状态，记录业绩触发、后续价格表现、观察阶段与是否仍值得跟踪；适合承接“业绩好但不一定马上涨”的情况。 |
| 板块、题材与涨价链 | `dragon_head_candidate` | 龙头 | 专题工具 | 从同题材或同板块中找辨识度更高的核心票。 | 综合涨幅排名、强度、成交、题材位置、同板块对照和主线证据，判断是否更像板块核心而不是普通跟涨。 |

| 板块、题材与涨价链 | `theme_core_mapper` | 题材 | 专题工具 | 把个股业务映射到题材主线，判断有没有想象空间。 | 结合主营、公告、新闻、产业链角色和同题材个股，给出业务标签、主题标签与主线判断；用于补“这家公司到底炒什么”。 |

| 短线工具 | `shortline_hub` | 短线 | 工具输出 | 汇总短线强势、观察和高风险移动票，辅助盘中/盘后快速查看。 | 聚合短线涨幅、量能、题材、风险标记和候选池状态；第一版页面只展示其命中关系，不单独展开短线交易规则。 |

## 3. 当前边界

- 页面只能展示复盘产物中已经写出的信号；如果某个专题策略没有写入 `triggered_strategies / signal_keys / signal_types`，页面不会凭空判断命中。
- 页面现在会做“读层质检”，但这层只作为阅读提示和排序辅助，不替代各策略脚本的真实筛选阈值，也不默认隐藏股票。
- `业绩 × 板块 × 位置 × 想象空间` 暂时还不是一个独立综合评分；第一版先解决单票视角和策略覆盖可见性。
- `scripts/run_personal_strategy_matrix.py` 当前默认只编排 K 线/业绩缓存预热和 `run_fast_review_bundle.py` 支持的信号；专题策略如果还停留在独立脚本或独立 snapshot 中，后续需要单独接入统一 runner。
- 后续如果新增个人策略，需要同步更新 `src/services/personal_strategy_matrix_service.py` 和本文档；前端不再维护独立策略清单。

## 4. 当前阅读提示口径

- 这层提示只复用 `fast_review_stock_overview.csv` 里已经写出的字段，不额外补网络数据。
- 当前主要参考：
  - `matched_strategy_count` 是否有共振；
  - `stock_review_lane` 是否仍停留在观察层；
  - `today_change_pct` 是否当天已经明显走坏；
  - `pure_chart_quality_passed / breakout_quality_score` 是否通过图形阅读层质检；
  - `earnings_strategy_score / earnings_strategy_gate_status / earnings_quality_score` 是否有业绩确认；
  - `capital_profile_score / relative_strength_score` 是否有资金和强度承接。
- 输出三档：
  - `优先看`：更像当天值得继续翻的票；
  - `可观察`：仍可看，但证据不够满；
  - `偏弱`：通常是单策略孤证、当天走弱、图形质检未过或业绩确认不足。
- 这不是新的选股脚本，也不会回写或改变底层策略命中结果；它只是个人策略页的统一展示层收口。
