# 个人策略精简方案

> 说明：这组文档只服务我个人在本仓库里的本地策略、个人复盘和个人运行习惯，不属于原工程通用文档。

状态：**草案（待确认，未执行）**  
最后更新：2026-09-24  
真源优先级：代码与脚本 > 本文档

## 0. 方向（2026-09-24 定调，本版重写）

本版按以下方向重写，替代上一版「4 + 2 + 1」目标形态：

- **策略多是表相，质量与适配才是根因**：现有策略大多写得一般、价值不大，日常「基本用不到」；
- **打法要与市场环境匹配**：熊市里业绩驱动不好用（利好兑现、beta 拖累），业绩线不再做每日主力；
- **按真实打法重组，而不是按信号堆叠**：
  - **吃股息**：要有一条能选出「高股息、可持续」池子的线——现在系统完全没有这个能力；
  - **短线**：条件明确 = **图形好 + 有催化**；
- 组织原则：每条线必须回答「**选什么、什么时候用、输出什么、什么时候淘汰**」，回答不了就退场。

## 1. 现状与问题（压缩）

- 页面 14 条策略，日常在跑的只有 4 条；约 36 个脚本中过半自 2026 年 4-5 月起无运行产物。
- 现有 4 条默认线全部是「信号探测器」（业绩 + 图形三类），没有按打法组织，也没有市场环境概念。
- 个人策略文档约 1.3 万行（其中修改记录 10,423 行），维护成本偏高。
- 结论：不是继续微调 14 条策略，而是**重组成 2-3 条有明确目的的打法线，其余退场**。

## 2. 目标结构：一守一攻 + 备用线

```
防守线（股息打底）     ← 熊市/震荡市主力，周频，低维护
进攻线（短线）         ← 图形好 × 有催化，日频
备用线（业绩/成长）    ← 环境转好再启用（regime 开关），当前只存档
```

- **市场环境开关（regime）** 决定：页面展示哪条线、bundle 跑哪些信号。
- 先手动开关（`market_regime: defensive / balanced / offensive`，默认 `defensive`），后续可选自动建议（指数均线/成交额）。

## 3. 每条线的定义

### 3.1 防守线：股息打底（新建）

| 项 | 内容 |
| --- | --- |
| 目的 | 熊市/震荡市里以现金回报为主，降低交易频率 |
| 适用环境 | defensive / balanced |
| 入选条件（草案） | 连续分红 ≥5 年；股息率（TTM）≥ 4%；派现率 30%-80%；近 3 年净利与经营现金流为正；剔除一次性大额分红（卖资产式）；低波动/回撤约束；排除 ST/科创/北交 |
| 数据来源 | Tushare `daily_basic`（按 trade_date 快照一次拉全市场 `dv_ttm`，规避限频）→ 粗筛 Top N → 增量缓存 `dividend`（分红历史）与 `fina_indicator`（现金流） |
| 输出 | `dividend_income_candidates.csv/md`（周频）+ 读层「防守区」 |
| 频率 | 周频（红利用不着每天看） |
| 预期形态 | 高股息主体通常集中在银行、煤炭、电力公用、交运（高速/港口）、运营商等成熟现金牛；以筛选结果为准 |
| 淘汰条件 | 连续 3 个月不使用 → 回炉重审 |

### 3.2 进攻线：短线 = 图形 × 催化（重组）

| 项 | 内容 |
| --- | --- |
| 目的 | 博取短期弹性；条件必须同时满足「图形好 + 有催化」 |
| 适用环境 | 全环境（defensive 下缩量展示） |
| 图形件（复用现有） | `hundred_day_high`（突破）/ `daily_slow_rise`（慢涨启动）/ `long_base_release`（平台释放）+ 量能与均线确认 |
| 催化件 | `industry_catalyst_registry` 扩充 + 每日「催化清单」（人工/新闻维护，覆盖涨价、事件、题材） |
| 时效 | 信号日 ≤ 3 个交易日 |
| 输出 | 每日「短线观察」区块：图形 ∩ 催化，按 催化强度 × 图形质量 排序 |
| 频率 | 日频 |
| 现状缺口 | 催化 registry 目前只覆盖 6 个行业主题；「催化清单」机制是本期要补的重点 |
| 淘汰条件 | 图形件与催化件长期无交集 → 分别退回纯图形观察 |

### 3.3 备用线：业绩/成长（条件启用）

- 保留 `earnings_surprise` 与 `earnings_observation` 的能力；
- defensive 模式下**只存档不展示**（或周频跑一次存档）；
- regime 切到 balanced/offensive 时恢复每日展示。

### 3.4 环境开关（regime）

- 配置位置：`config/local_strategy_profile.json` 新增字段；读层（`personal_strategy_matrix_service` / bundle 输出）按开关过滤展示线。
- 默认 `defensive`（与当前市场判断一致）。

## 5. 质量门槛与淘汰机制

- 每条线必须写清五件事：**目的 / 入选条件 / 输出 / 适用环境 / 淘汰条件**；写不清的不开工。
- 新东西的准入：只加「证据维度」，不加新信号堆叠；小样本后验（复用 `evaluate_signal_snapshot_performance.py` / `run_signal_performance_bundle.py` 等现有工具）通过才上页面。
- 页面策略数上限 8；要新增先撤一个。
- 90 天未运行 → 下一个季度回顾自动进冻结候选。

## 7. 参数决策（2026-09-24 定稿）

- 股息率门槛：**4%** 确认（默认值）。
- 连续性：**≥5 年** 确认（默认值）。
- 央国企偏好：**采用软偏好**——输出实控人企业性质 `owner_type`，央企/地方国企 +3 分（`soe_bonus`），可用 `--no-prefer-soe` 关闭；不做硬过滤（避免池子缩得太小）。
- 派现率 >100%：保留不可持续标记（`payout_over_100`），不自动剔除，交由人工复核。

## 8. 验收与风险

验收：

- [ ] 股息线周频产出可用，页面出现「防守区」；
- [ ] 短线圈每日输出 图形∩催化；
- [ ] 页面策略收敛（防守 1 + 进攻 1 + 备用 2 折叠）；
- [ ] 冻结/文档瘦身按 Step 4 完成。

风险：

| 风险 | 缓解 |
| --- | --- |
| 股息筛选 ≠ 买入建议；除权/税收/再平衡需自行把握 | 输出只做池子与指标展示 |
| `daily_basic` 账号限频低（实测 1 次/分钟，高压下退化为 1 次/小时） | 快照本地缓存 30 天复用 + `--wait-minutes` 配额等待重试 + 连续限频快速放弃；分红/EPS 已改走 AKShare 批量（零配额） |
| 催化清单变成第二个「策略工厂」 | 清单只做维护表，不做自动评分体系 |
| 熊市判断失效（市场转好） | regime 手动切回，备用线即恢复 |

## 9. 决策记录

- **2026-09-24 / Step 1 股息线 MVP 代码落地**（待用户验收）：
  - 新增 `src/services/dividend_income_service.py`、`scripts/select_dividend_income_candidates.py`、`tests/test_dividend_income_service.py`（10 用例全绿）。
  - 实盘探测结论：Tushare `stock_basic` 可用；`daily_basic` 可用但账号常态化限频（1 次/分钟，高压下退化为 1 次/小时）；`fina_indicator` / `income` 无权限。AKShare `stock_fhps_em` 实测可批量拉全市场分红送配 + 每股收益（免费无配额），已作为分红与 EPS 主数据源（缓存 30 天）。
  - 限频对策：① 快照本地缓存优先（30 天，二次运行零调用）；② 在线探测最多 3 个工作日、连续 2 次限频即本轮放弃（快速失败）；③ `--wait-minutes`（默认 75）在配额恢复窗口内退避轮询重试；④ 逐票 `dividend` 只做兑底，EPS 按 AKShare → `close/pe_ttm` 降级，输出 `eps_source` 字段可审计。

- **2026-09-24（当晚）/ 参数定稿 + 最近 5 日实盘**：§7 门槛 4% / ≥5 年确认；央国企采用软偏好（+3 分，`--no-prefer-soe` 可关）。因 Tushare `daily_basic` 配额整晚受限，新增 `scripts/refresh_local_daily_basic_snapshot.py`（腾讯行情 + 分红缓存构造代理快照，`snapshot_source=tencent_proxy`），对 2026-09-18/21/22/23/24 五个交易日各跑一轮：候选 273-284、合格 236-246，Top20 逐日重合 ≥19/20（池子稳定，漂移来自价格小幅波动），产物在 `data/dividend_income/<日期>/`。
