## 4. 三个口径反例与投票边界

- 个股持股比例：H₀=10、S₀=100，H₁=10、S₁=100，不管股价涨跌比例都为 10%；不能套基金收益漂移。若股本变为 120、持股数仍 10，比例降至 8.3333%，是分母摊薄，数量贡献为零，不能说净卖出。送转则先统一两期股数单位。
- 预期差：年度 EPS 5 元与三季累计扣非净利 5 亿元不做减法；E=−1、A=−0.5 可列同单位绝对差 +0.5，按本卡不报百分比，不能因“同比仍降”抹去比预期好的事实。
- 分块投票：`恶化/改善/改善/未知` 为分歧；`改善/未知/未知/未知` 为未知；`盈利改善/质量改善/机构稳定/景气未知` 通过两来源族时为改善，显示 3/4；`盈利稳定/质量稳定/机构未知/景气未知` 只有财务族，须标财务单源状态（弱），整体未知。所有块的阈值/覆盖未登记时仍是未知，不由文字描述代投票。

WHERE code IN ('300274','600519','601398','002491','601012','000300')
GROUP BY code;
