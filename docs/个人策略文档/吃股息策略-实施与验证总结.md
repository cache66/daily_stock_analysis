## 3. 当前筛选与评分体系（v3）

### 3.1 硬条件

- 股息率（TTM）≥ 4%（`--min-yield` 可调）
- 连续分红 ≥ 5 年（`--min-years` 可调）；上市 ≥ 5 年（粗过滤）
- 只计入「已实施」分红；派现率 >100% 仅标记（`payout_over_100`）不剔除
- 样本口径：排除 ST/PT、科创板、北交所（与个人策略共享口径一致）

### 3.2 评分构成（2026-09-24 版本）

| 评分块 | 上限 | 说明 |
| --- | --- | --- |
| 股息率 | 35 | 自 3% 起每 1 个百分点 7 分 |
| 连续性 | 20 | 每年 4 分 |
| 盈利质量 | 25 | EPS 基准 ≤10 + ROE 分档 ≤8 + 现金流覆盖 ≤7 |
| 低波动 | 12 | 年化波动率分档（20/28/35%）；最大回撤 ≤-30% 再 -3 |
| 央国企 | +3 | `--no-prefer-soe` 可关（软偏好，不硬过滤） |

调整项：价格趋势 -3/-8/-12（近半年续跌再 -2，下限 -14）；分红成长 +2 / -3；v3 追加：趋势闸门 +4 / -6、扣非质量 -3、ROE 趋势 -2、PE 极端 -2。

### 3.3 主要标签

`trend_above_ma200` / `trend_breakdown`；`np_deduct_low`；`roe_declining`；`pe_extreme`；`total_return_1y_negative` / `price_fall_1y` / `price_fall_severe_1y` / `price_fall_6m`；`dividend_growing` / `dividend_shrinking`；`roe_weak` / `roe_negative_year`；`ocfps_negative` / `cf_below_dividend`；`payout_over_100` / `payout_high` / `payout_unknown`；`cyclical_industry`；`yield_outlier`。

## 4. 数据链路与已知坑（重要）

- **行情口径**：`data/cache/history/{cn,hk,us}/<code>.csv` + json 元数据；磁盘缓存优先、缺口增量补齐并回写。
  ⚠️ json 的 `source` 只反映**最后一个写入者**：曾出现 AKShare 前复权旧段与 Tushare 原始新段拼接的「接缝」失真（实例：荣晟环保 +10.4% vs 真实 +3.3%）。已对候选重建一次；本策略统一「**原始涨跌 + TTM 股息 ≈ 含息净回报**」口径。
- **Tushare 配额**：`daily_basic` 常态限频，失败会加重惩罚（曾退化到 1 次/小时）；对策 = 代理快照（腾讯行情 + AKShare 分红缓存，`snapshot_source=tencent_proxy`）。**不要开后台重试循环**。
- **分红历史**：AKShare `stock_fhps_em` 按报告期批量（免费无配额，缓存 30 天），是股息率 / 连续分红的主数据源。
- **业绩面**：同花顺年度摘要逐票（ROE / 每股经营现金流 / 扣非 / 营收 / 净利），缓存 90 天；当前约 500 只有缓存，缺缓存按中性处理。
- **回测专用深历史**：共享缓存仅 260 根 K 线（不够 MA200 / 波动率）→ Baostock 抓取独立目录 `data/cache/backtest_history/cn/`（800 只池子股），**不污染实盘链路**。

## 6. 平台对照（东方财富 / 问财）

- 等价条件对照（2026-09-24）：问财组 97% 落在本策略 v2 池内；高息陷阱比例：东财组 59% vs 本策略池 69%（逐条对照文件 `data/runtime/compare_platform_conditions_20260924.csv`）。
- 差异化：本策略 Top20 年化波动率中位 22.7%，低于对照组 28~29%——**低波 + 质量过滤是主要边际优势**。
- 结论：纯筛股能力与商业平台同级；优势在结果纪律（低波、陷阱标记、全字段可解释）。

## 7. 点时回测（2024-06 ~ 2026-06，24 期月度调仓）

方法：月末最后交易日按 v3 打分，等权持有 1 个月滚动换仓；PIT 股息率 = 过去 12 个月**已除权**现金分红之和 ÷ 月末收盘；基本面只用报告期 ≤ T-1 的数据；收益含窗口内除权现金流；基准中证红利 000922（价格指数，未含分红再投）。

| 组合 | 累计 | 年化 | 月胜率 | 最大回撤 | 月均 |
| --- | --- | --- | --- | --- | --- |
| 策略 Top20 | +11.5% | +5.6% | 54.2% | -13.0% | +0.55% |
| 合格池等权 | **+20.3%** | **+9.7%** | 58.3% | -13.2% | +0.89% |
| 中证红利 000922（价格） | -1.8% | -1.0% | 47.8% | -14.4% | +0.03% |

因子诊断：评分 RankIC **-0.010**；股息率 Q5-Q1 -0.29%/月；距 200 日线 IC **-0.016**；波动率 IC **-0.006**；「站上 200 日线 vs 深度跌破」月均差 **+0.05%**。

**三条结论**：

1. **合格池等权是有效基座**（含息 +9.7%/年，显著优于中证红利价格口径）；
2. **评分排序没有区分度**（Top20 跑输池子），高息优先把仓位引向高息陷阱；
3. **趋势闸门 / 低波因子未验证出增量**；此前「站上 200 日线更优」被证实是后视偏差。

已知偏差：幸存者偏差（池子取自 2026-07 缓存）；缓存接缝；业绩面仅部分标的；基准未含分红。产物：`data/runtime/backtest_dividend_income_{monthly,holdings}_*.csv`。

## 8. 行业结构分析与门槛敏感性（2026-09-24）

- 合格池 236 只覆盖 **66 个行业**；Top20 构成：银行 8、水运 3、家电 2、医疗 2、传媒 2、乳制品 1、服饰 1、商业 1 →「传统行业」观感来自 Top 榜的银行/家电堆叠。
- 非银行/家电/食饮/服饰共 **166 只**；代表：中远海控 76.9、九强生物 68.8、中原传媒 68.2、新奥股份 66.0、四川路桥 66.0、粤高速 65.8、申能股份 65.7、洪城环境 65.3、中国神华 62.3。
- 结构性原因：**股息率 ≥4% + 连续分红 5 年** 天然只属于成熟行业（银行/公用/交运/资源/纺服/家电/食饮），科技成长股普遍进不了门槛。
- **门槛敏感性（3.5% vs 4%，同一快照）**：合格 236 → **320**（+84）、行业 66 → **74**；新增行业：元器件、批发业、日用化工、水力发电、电信运营、石油开采、矿物制品、装修装饰；新增代表：宁沪高速 70.4、建设银行 68.3、长江电力 68.2、上港集团 69.0、工商银行 67.2、青岛港 66.3、瀚蓝环境 63.1、陕西煤业 61.2、海康威视 60.2、中国中车 48.5；**原 Top10 全部保留（10/10）** → 放宽门槛是「**加宽**」不是「替换」。

## 9. 未决问题与后续方向（下次讨论从这里开始）

1. **评分排序重构**：RankIC≈0 → 横截面标准化、降低股息率权重、行业中性化；
2. **行业分散**：榜单层行业限额（计划新增 `--max-per-industry`）或组合层行业权重上限；
3. **组合构建**：池子等权做基座 + Top20 观察，还是改良排序后集中持有；再平衡频率与单票上限；
4. **门槛**：维持 4% 还是 3.5% + 行业配额（3.5% 已验证「加宽不替换」）；
5. **因子增量验证**：用回测分层逐个检验分红成长 / 扣非质量 / 现金流覆盖的边际贡献；
6. **回测增强**：更长区间、全收益基准（含分红再投）、真实财报披露截点。

## 10. 运行手册（当前可用命令）

```bash
# 最新交易日筛选（缓存优先，日常推荐；最新完整交易日以实际日历为准）
.venv-linux/bin/python scripts/select_dividend_income_candidates.py --snapshot-date 2026-09-24 --cache-only

# 放宽门槛 + 突破 prefilter 截断（3.5% 全量）
.venv-linux/bin/python scripts/select_dividend_income_candidates.py --snapshot-date 2026-09-24 \
  --min-yield 3.5 --prefilter-limit 0 --output-dir data/runtime/dividend_income_y35_full_20260924

# 点时回测（深历史已缓存时增量很快；--no-deep-fetch 可完全离线）
.venv-linux/bin/python scripts/backtest_dividend_income.py

# Tushare 配额受限时构造代理快照
.venv-linux/bin/python scripts/refresh_local_daily_basic_snapshot.py --days 5
```

产物：`data/dividend_income/<日期>/`（`dividend_income_candidates.csv` / `.md` / `summary.json`）；回测产物 `data/runtime/backtest_dividend_income_*.csv`；缓存根 `data/cache/dividend_income/`。
