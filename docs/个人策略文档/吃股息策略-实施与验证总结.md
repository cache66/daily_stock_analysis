## 3. 当前筛选与评分体系（v3）

### 3.1 硬条件

- 股息率（TTM）≥ 4%（`--min-yield` 可调）
- 连续分红 ≥ 5 年（`--min-years` 可调）；上市 ≥ 5 年（粗过滤）
- 只计入「已实施」分红；派现率 >100% 仅标记（`payout_over_100`）不剔除
- 样本口径：排除 ST/PT、科创板、北交所（与个人策略共享口径一致）

### 3.2 评分构成（2026-09-24 版本）

| 评分块 | 上限 | 说明 |
| --- | --- | --- |
| 股息率 | 35 | 自 3% 起每 1 个百分点 7 分 |
| 连续性 | 20 | 每年 4 分 |
| 盈利质量 | 25 | EPS 基准 ≤10 + ROE 分档 ≤8 + 现金流覆盖 ≤7 |
| 低波动 | 12 | 年化波动率分档（20/28/35%）；最大回撤 ≤-30% 再 -3 |
| 央国企 | +3 | `--no-prefer-soe` 可关（软偏好，不硬过滤） |

调整项：价格趋势 -3/-8/-12（近半年续跌再 -2，下限 -14）；分红成长 +2 / -3；v3 追加：趋势闸门 +4 / -6、扣非质量 -3、ROE 趋势 -2、PE 极端 -2。

### 3.3 主要标签

`trend_above_ma200` / `trend_breakdown`；`np_deduct_low`；`roe_declining`；`pe_extreme`；`total_return_1y_negative` / `price_fall_1y` / `price_fall_severe_1y` / `price_fall_6m`；`dividend_growing` / `dividend_shrinking`；`roe_weak` / `roe_negative_year`；`ocfps_negative` / `cf_below_dividend`；`payout_over_100` / `payout_high` / `payout_unknown`；`cyclical_industry`；`yield_outlier`。

## 4. 数据链路与已知坑（重要）

- **行情口径**：`data/cache/history/{cn,hk,us}/<code>.csv` + json 元数据；磁盘缓存优先、缺口增量补齐并回写。
  ⚠️ json 的 `source` 只反映**最后一个写入者**：曾出现 AKShare 前复权旧段与 Tushare 原始新段拼接的「接缝」失真（实例：荣晟环保 +10.4% vs 真实 +3.3%）。已对候选重建一次；本策略统一「**原始涨跌 + TTM 股息 ≈ 含息净回报**」口径。
- **Tushare 配额**：`daily_basic` 常态限频，失败会加重惩罚（曾退化到 1 次/小时）；对策 = 代理快照（腾讯行情 + AKShare 分红缓存，`snapshot_source=tencent_proxy`）。**不要开后台重试循环**。
- **分红历史**：AKShare `stock_fhps_em` 按报告期批量（免费无配额，缓存 30 天），是股息率 / 连续分红的主数据源。
- **业绩面**：同花顺年度摘要逐票（ROE / 每股经营现金流 / 扣非 / 营收 / 净利），缓存 90 天；当前约 500 只有缓存，缺缓存按中性处理。
- **回测专用深历史**：共享缓存仅 260 根 K 线（不够 MA200 / 波动率）→ Baostock 抓取独立目录 `data/cache/backtest_history/cn/`（800 只池子股），**不污染实盘链路**。

## 7. 点时回测（2024-06 ~ 2026-06，24 期月度调仓）

方法：月末最后交易日按 v3 打分，等权持有 1 个月滚动换仓；PIT 股息率 = 过去 12 个月**已除权**现金分红之和 ÷ 月末收盘；基本面只用报告期 ≤ T-1 的数据；收益含窗口内除权现金流；基准中证红利 000922（价格指数，未含分红再投）。

| 组合 | 累计 | 年化 | 月胜率 | 最大回撤 | 月均 |
| --- | --- | --- | --- | --- | --- |
| 策略 Top20 | +11.5% | +5.6% | 54.2% | -13.0% | +0.55% |
| 合格池等权 | **+20.3%** | **+9.7%** | 58.3% | -13.2% | +0.89% |
| 中证红利 000922（价格） | -1.8% | -1.0% | 47.8% | -14.4% | +0.03% |

因子诊断：评分 RankIC **-0.010**；股息率 Q5-Q1 -0.29%/月；距 200 日线 IC **-0.016**；波动率 IC **-0.006**；「站上 200 日线 vs 深度跌破」月均差 **+0.05%**。

**三条结论**：

1. **合格池等权是有效基座**（含息 +9.7%/年，显著优于中证红利价格口径）；
2. **评分排序没有区分度**（Top20 跑输池子），高息优先把仓位引向高息陷阱；
3. **趋势闸门 / 低波因子未验证出增量**；此前「站上 200 日线更优」被证实是后视偏差。

已知偏差：幸存者偏差（池子取自 2026-07 缓存）；缓存接缝；业绩面仅部分标的；基准未含分红。产物：`data/runtime/backtest_dividend_income_{monthly,holdings}_*.csv`。

## 9. 未决问题与后续方向（下次讨论从这里开始）

1. **评分排序重构**：RankIC≈0 → 横截面标准化、降低股息率权重、行业中性化；
2. **行业分散**：榜单层行业限额（计划新增 `--max-per-industry`）或组合层行业权重上限；
3. **组合构建**：池子等权做基座 + Top20 观察，还是改良排序后集中持有；再平衡频率与单票上限；
4. **门槛**：维持 4% 还是 3.5% + 行业配额（3.5% 已验证「加宽不替换」）；
5. **因子增量验证**：用回测分层逐个检验分红成长 / 扣非质量 / 现金流覆盖的边际贡献；
6. **回测增强**：更长区间、全收益基准（含分红再投）、真实财报披露截点。

### 13.1 工程修复：深历史缓存“分段截断”

- 现象：2024-2026 段重跑时池子 255→54、大批票被误剔除（平安银行/美的/格力等）。
- 根因：`ensure_deep_history` 只校验深历史**首日**、抓取时**整文件覆盖**；早期分段运行把文件截断到当时 end（282 只截到 2021-12、317 只到 2024-06），更晚区间回测误判“已就绪”，短序列替换长序列 → 月末 bar 越界被剔除。
- 修复：`_deep_ready` 增加**末日期校验**；抓取结果**与旧文件合并**（日期并集，重叠以新为准）；934 只深历史统一重抓 2017-11 ~ 2026-06（成功 934 / 失败 0）。
- 影响：修复后三段池子恢复正常（seg3 每月 212~317 只）；**10-05 版分段数字与 §12 相关表述作废**。

### 13.5 结论（覆盖 §7 / §12 的旧口径）

1. **长区间（69 个月）现有评分 Top20 优于池子**：年化 +19.3% vs +14.7%（累计 +176% vs +120%），月胜 61%、回撤相当；2020-2024 两段大幅跑赢（+34.8%/26.1%、+22.0%/12.6%）。
2. **近两年（2024-06~2026-05）评分排序失效**：Top20 +5.8% < 池子 +8.5%（IC -0.012）；此段 50-50 变体 (+9.8%) 更优——排序红利存在周期性衰减。
3. **50-50 非长区间更优解**（+17.5% < 评分 +19.3%），仅近段占优，不建议通用替换。
4. **评分可精简**：质量块（ROE/扣非）与连续性块（分红年数/成长）在 6 年样本上稳定负向；正 IC 主要由低波、现金流、派现率、低估值贡献——“降质量/连续性权重、强化现金流与派现”是下一轮候选方向（本轮不动代码）。
5. §7/§12 的“Top 跑输/不输”之争**主要源于数据**（污染/截断），而非策略本身。

### 13.6 组合执行说明（v1.0，2026-10-06 定稿；同日切换「精简B」排序）

- **基座**：合格池等权（4% 门槛约 230~320 只；实操抽 30~50 只等权分散）。证据：三段年化 +26.1%/+12.6%/+8.5%，全正。
- **门槛**：**4% 核心 + 3.5% 扩展层**——核心池主选样；核心不足或需额外分散时启用扩展层（“加宽不替换”已验证：236→320 只、行业 66→74）。
- **抽样**：**30~50 只等权、单票 ≤4%**；行业不设硬限额（已验证硬限额整体砍收益），自然分散+提示。
- **再平衡**：**季度检视 + 分红再投**；不做月频（研究口径≠执行口径，控制换手与红利税摩擦）。
- **选样排序（2026-10-06 已切换）**：默认「精简B」横截面综合分（0.40 股息率 + 0.30 低波 + 0.30 现金流覆盖，见 §13.7）；原评分的“长区间 +4.6pp”红利保留为对照列（`dividend_score`）。落地点：池产物新增 `trim_b_score` 并按其排序（波动率覆盖 <50% 自动回退评分）；`analyze_dividend_top100.py` 体检与 `make_dividend_three_tiers.py` 三档同步优先新口径。
- **T 仓**：仅用机动仓（规则同 `dividend_t_watch.py`：-3/-5/-7% 分批，+2~3% 或 10 日内止盈，破 MA200 停）。
- **税务**：长持 >1 年红利税 0；做 T 注意先进先出与持股期。

### 13.7 精简评分实验结果（2026-10-06，离线）

**方法**：面板无评分分块明细 → 以“因子直构”近似精简方向（去掉稳定负向的质量/连续性簇，保留/强化正向簇）；`experiment_dividend_rerank.py` 新增两变体，合并+三段统一净化后跑 Top20 月频（等权、含息）：

- 精简A = 0.30·z(股息率) + 0.30·z(−波动) + 0.20·z(现金流覆盖) + 0.20·z(派现率)
- 精简B = 0.40·z(股息率) + 0.30·z(−波动) + 0.30·z(现金流覆盖)

**结论**：
1. **精简B（股息+低波+现金流）为最优切换候选**：合并年化基本持平（+19.1% vs +19.3%），回撤三段全部更小（合并 -10.6% vs -13.0%），且**近两年显著修复**（+12.3% vs +5.8%，并跑赢池子 +8.5%）；IC 三段均非负。
2. 精简A（含派现）IC 最高（合并 +0.043），但 2020-2021 让利较多，列为备选。
3. 历史 z_mix 类复杂重构依旧全弱；“去掉负向簇、保留股息+低波+现金流”是本样本唯一同时改善 收益/回撤/IC 的方向。
4. 口径提示：因子方向来自同一 6 年样本（样本内探索）；但权重（0.4/0.3/0.3）为先验设定未经优化，且“2020-2024 设定 → 2024-2026 显著改善”具备半样本外性质。**已于 2026-10-06 切换实盘排序（池产物/体检/三档清单/示例组合）为精简B**：服务侧横截面 z 分与实验 `trim_yvc` 口径一致（去极值/中位数填充/ddof=0），波动率覆盖率 <50% 自动回退综合评分；新旧序对照（9/30 池 Top10）：评分序=华特达因/新媒股份/中创智领/…（首位 91.0）→ 精简B 序=华夏银行/光大银行/兴业银行/平安银行/格力电器/…。实现与验证见 `个人策略修改记录.md` 2026-10-06（续2）。
5. **股息陷阱过滤验证（2026-10-06 晚，报告扩至 11 变体）**：给精简B加“选择前剔除深跌票”过滤（含息≤-30% / ≤-15%）——三段+合并均未获收益改善（合并年化 19.1% → 18.4%/18.5%、回撤 -10.6% 持平，近段 12.3% → 11.2%/10.5%），**过滤不并入正式排序口径**（池/体检/三档保持裸 B）；改为**执行层防线**：示例组合（v0.3）剔除 `price_fall_severe_1y` 深跌票（9/30 池全剔 34 只，前 40 内剔五粮液/分众传媒/欧派家居），“按池前 N 只直接执行”应改为走三层清单或叠加执行层过滤。
6. **“只选含息为正”严格版（2026-10-06 深夜，追问验证）**：要求选股时近一年含息回报 >0（“跌幅未超股息”）——合并年化 +20.0%（vs 裸 B +19.1%），但结构是**动量倾斜**：修复段大赚但回撤加深（2020-21 +32.3%（回撤 -11.3%）vs +26.6%/-5.9%；22-24 +23.3% vs +20.4%），**近两年熊市段明显更差（+7.9% vs +12.3%，-4.4pp）** → 该口径在当下市场逆风、偏离吃息防守定位，**不作选股硬条件**（名单保留 `含息≈` 展示列；逆风期恰是“拿着跌过的票”才赢）；当前池 236 只中“含息为正”仅 74 只（31%）。
