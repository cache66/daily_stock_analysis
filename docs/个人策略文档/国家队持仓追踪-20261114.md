# 国家队持仓追踪（社保 / 汇金 / 证金 / 国新）

> 建立 2026-11-14。脚本：`scripts/track_national_team_holdings.py`。
> 配套（ETF 视角）：`scripts/etf_flow_history.py` + `scripts/analyze_etf_national_team.py`。

## 1. 为什么单独立一条

2026 年熊市里，很多决策隐含一个假设：「国家队会托底」。
本模块把这个假设变成可验证的数据，用于回答三个问题：

1. 国家队现在还有多少仓位（分主体）？
2. 相比上季度，是加还是减？新进几只、退出几只？
3. 撤的是哪些票、留的是哪些票 → 护盘的真实边界在哪？

## 2. 数据与口径（重要）

| 项 | 说明 |
| --- | --- |
| 数据源 | 东财「十大流通股东持股分析」`stock_gdfx_free_holding_analyse_em(date=报告期)` |
| 粒度 | 季度（3/31、6/30、9/30、12/31），每季约 5.5~5.7 万条记录 |
| 缓存 | `data/cache/national_team/gdfx_<报告期>.csv`（单季约 9MB） |
| 产物 | `data/strategy_review/national_team_<报告期>/`（report.md / summary.json / diff_*.csv） |
| 主体识别 | 按「股东名称」关键字匹配：`全国社保基金` / `中央汇金投资有限` / `中央汇金资产` / `中国证券金融` / `国新投资` / `梧桐树投资` |

**三个必须记住的口径限制：**

1. **只有前十大会被统计。** 显示「退出前十大」= 减到第 11 名以后，**不等于清仓**。因此报告统一用「退出前十大」措辞，不用「清仓」。
2. **ETF 是盲区。** 汇金 2024 年起通过宽基 ETF（510300/510050 等）护盘，这部分不进十大股东名单，本脚本看不到。要判断完整图景必须配 ETF 份额数据。
3. **市值 ≠ 操作。** 市值变化同时受股价与持仓影响。判断方向只看「只数变化」和「新进只数」。
   - 特别地，`汇金投资`（母公司，持四大行）**持股数常年不变**，其市值波动 = 银行股价波动，脚本已在报告里单独注记。

## 3. 用法

```bash
# 自动识别最新可用季度（按披露滞后推导），并与上一季度对比
./.venv-linux/bin/python scripts/track_national_team_holdings.py

# 指定季度 + 基线
./.venv-linux/bin/python scripts/track_national_team_holdings.py --quarter 20260930 --baseline 20250630

# 出最近 6 个季度的趋势表
./.venv-linux/bin/python scripts/track_national_team_holdings.py --history 6

# 离线（只用缓存；缓存缺失的季度自动跳过）
./.venv-linux/bin/python scripts/track_national_team_holdings.py --history 8 --cache-only

# 强制重拉（东财限流会重试 4 次，单季约 3-5 分钟）
./.venv-linux/bin/python scripts/track_national_team_holdings.py --quarter 20260930 --force
```

**抓取成本提示**：单季全市场约 113 页请求、3-5 分钟。东财会限流（`RemoteDisconnected`），
脚本内置 4 次递增等待重试，但**不要并发跑多个季度**。首次建库可一次性把历史季度补全，
之后每季只需抓 1 次。

**建议节奏**：季报披露后 1~2 个月跑一次（Q1 报→5 月、Q2 报→9 月、Q3 报→11 月、Q4 报→次年 5 月）。

## 5. 判读要点

1. **看只数，不看市值。** 市值受股价影响，只数减少才是真退出。
2. **「新进 0 只」= 单边卖出信号。** 有出无进说明不是调仓，是撤离。
3. **汇金投资（四大行）常年不变。** 它的市值波动等于银行股波动，不代表操作；银行这轮上涨不是国家队买的。
4. **社保是唯一会主动调仓的主体。** 方向可参考，但量级（1,700 亿）远小于证金的退出（5,000+ 亿）。
5. **护盘 = 护指数，不是护个股。** 剩余仓位集中在金融权重，说明维稳成本优先投向指数权重板块。
6. **ETF 必须一起看。** 个股退出可能部分转成 ETF 承接，单看本模块会高估撤退力度（但证金的卖出无法用 ETF 解释）。
