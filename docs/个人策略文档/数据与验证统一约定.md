# 数据与验证统一约定（个人线）

状态：**2026-09-25 生效**；适用范围：`docs/个人策略文档` 下所有线的新增 / 改造代码。
目的：终结"框架有下载能力、个人脚本又自造下载"的双轨状态，统一数据入口与验证口径。

## 1. 数据入口（统一走框架，禁止新直连）

- 行情 / 历史 K 线：`DataFetcherManager`（本地 `data/cache/history` 缓存优先、缺口自动补齐）；批量研究场景用 `KlineSelectorService.build_fast_a_share_manager()`。
- 快照 / 基本面 / 新闻：优先复用框架服务（`fundamental_adapter`、`SearchService`、`daily_basic` 本地快照机制）。
- **新增脚本不得直接 `import akshare / tushare / baostock / efinance` 或 `requests` 裸拉数据**（除下方豁免清单）。
- 缓存 / 产物位置：统一 `data/cache/**` 或 `data/<线>/**`，不新造根目录。
- 配额受限场景：沿用"本地快照 + 等待窗口重试"模式（参考 `refresh_local_daily_basic_snapshot.py` 与 `select_dividend_income_candidates.py`）。

## 2. 验证口径（只准一套）

- 信号表现评估：`scripts/evaluate_signal_snapshot_performance.py` / `scripts/run_signal_performance_bundle.py`。
- 策略点回测：`scripts/backtest_*.py`（点时口径、基准对比、含息处理）。
- 因子 / 评分区分度：后续统一迁移到 qlib IC 检验（见《开源工具融合规划》）；在迁移前，暂用回测脚本内的 RankIC / 分层输出。
- **禁止再新造第二套回测 / 评估脚本**；现有重复能力只做合并，不做扩建。

## 4. 新脚本准入清单（提交前自查）

- [ ] 数据来自 `DataFetcherManager` / 框架服务（或命中豁免）；
- [ ] 产物落在约定目录，失败可重跑且不污染既有缓存；
- [ ] 有对应的最小测试（pytest）；
- [ ] 通过（或复用）统一验证口径，不在脚本里内嵌第二套回测；
- [ ] 更新相关文档与 `docs/CHANGELOG.md`。
