# 数据与验证统一约定（个人线）

状态：**2026-09-25 生效**；适用范围：`docs/个人策略文档` 下所有线的新增 / 改造代码。
目的：终结"框架有下载能力、个人脚本又自造下载"的双轨状态，统一数据入口与验证口径。

## 1. 数据入口（统一走框架，禁止新直连）

- 行情 / 历史 K 线：`DataFetcherManager`（本地 `data/cache/history` 缓存优先、缺口自动补齐）；批量研究场景用 `KlineSelectorService.build_fast_a_share_manager()`。
- 快照 / 基本面 / 新闻：优先复用框架服务（`fundamental_adapter`、`SearchService`、`daily_basic` 本地快照机制）。
- **新增脚本不得直接 `import akshare / tushare / baostock / efinance` 或 `requests` 裸拉数据**（除下方豁免清单）。
- 缓存 / 产物位置：统一 `data/cache/**` 或 `data/<线>/**`，不新造根目录。
- 配额受限场景：沿用"本地快照 + 等待窗口重试"模式（参考 `refresh_local_daily_basic_snapshot.py` 与 `select_dividend_income_candidates.py`）。

## 2. 验证口径（只准一套）

- 信号表现评估：`scripts/evaluate_signal_snapshot_performance.py` / `scripts/run_signal_performance_bundle.py`。
- 策略点回测：`scripts/backtest_*.py`（点时口径、基准对比、含息处理）。
- 因子 / 评分区分度：后续统一迁移到 qlib IC 检验（见《开源工具融合规划》）；在迁移前，暂用回测脚本内的 RankIC / 分层输出。
- **禁止再新造第二套回测 / 评估脚本**；现有重复能力只做合并，不做扩建。

## 4. 新脚本准入清单（提交前自查）

- [ ] 数据来自 `DataFetcherManager` / 框架服务（或命中豁免）；
- [ ] 产物落在约定目录，失败可重跑且不污染既有缓存；
- [ ] 有对应的最小测试（pytest）；
- [ ] 通过（或复用）统一验证口径，不在脚本里内嵌第二套回测；
- [ ] 更新相关文档与 `docs/CHANGELOG.md`。

## 5. 价格口径约定（T0.4，2026-09-26 起）

- **评估/回测的唯一价格真源 = `stock_daily`（前复权口径）**；统一重建入口 `scripts/rebuild_stock_daily_qfq.py`（Baostock 前复权，覆盖式写回 + 前后异常扫描）。
- **信号快照 `metrics_payload.close` 禁止用于评估入场价**：实测 48.6% 样本与前复权收盘偏离 >2%（高送转/过期尺度券）；评估统一 `--entry-mode daily`，leaderboard 默认已切。
- 统一评估入口：`scripts/evaluate_signal_snapshot_performance.py`（v2t 成本 + `--tradability-filter entry` + `--entry-mode daily`）；一键刷新：`scripts/run_strategy_leaderboard.py`。
- 口径异常留档：`data/verification/qfq_contamination_fingerprint_20260926.csv`（重建前全历史指纹 20,363 条 / 395 只，覆盖 2024-06-11 起）。
- 巡检命令：`scripts/check_price_anomalies.py`（复用 `scan_abnormal_jumps` 同口径探超板跳变，默认带 45 天前收回看，避免窗口首日漏检）；重建前 2026 窗口基线已固化 `data/verification/qfq_fingerprint_2026_before_rebuild_20260926.csv`（10,456 条 / 369 只），重建后验收用 `--compare-baseline` 对该文件复跑（期望 已修复≈10,456 / 新增≈0）。
- 基准指数：`scripts/backfill_index_daily.py` 负责把指数日线补齐进 `stock_daily`（000300 已于 2026-09-26 入库 663 根、2024-01-02 起；裸代码的 canonical 按存储契约推导为股票路径 `sz000300`，与既有 000905 行一致）；评估器 / leaderboard 的 `--benchmark-code` 可直接使用。
- ⚠️ 历史磁盘缓存风险：`data/cache/history*` 与旧 `stock_daily` 同带“单日刻度接缝”（2026-09-26 抽查 386/386 吻合）；选择器 / PIT 消费缓存数据存在同等污染上界（≈3.65% 信号行，见 `data/verification/pit_contamination_impact_2026-08-04_2026-09-24.json`）。**状态（2026-09-27 收口）**：污染已量化（总体 3.65% < 5% 阈值）+ hdh 单线定向复核 19/19 通过 → **不触发 PIT 重跑**；`data/cache/history*` 清空重建降级为可选优化（仍注意：基于缓存重跑 PIT 前必须先重建缓存）。
- 新脚本消费价格时必须读 `stock_daily` 或 `DataFetcherManager` 的当前前复权链，不得把“快照期价格”与“当前复权价”混算。
