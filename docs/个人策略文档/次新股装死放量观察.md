### Step 3 · 跌幅双口径（关键）

```python
回撤%(含首日) = 最新收盘 / 上市后最高 - 1          # 含首日炒作高点，会虚高
回撤%(剔首日) = 最新收盘 / 上市第2日起最高 - 1     # 更接近"真实下跌"
较首日%      = 最新收盘 / 上市首日收盘 - 1        # 判断是"一路阴跌"还是"首日炒太高"
```

**必须三个一起看**。反例：电科思仪回撤 -50%，但「较首日」只有 -16.8%，
说明它没怎么跌、只是首日定价过高 → 不算"跌幅大"。

### Step 4 · 盘子过滤

```
流通市值 ≤ 30 亿   且   总市值 ≤ 200 亿
```

**两个都限**。只用流通市值会漏掉"流通盘小、总市值巨大"的解禁炸弹
（例：沈鼓集团流通 36 亿但总市值 537 亿）。

### Step 5 · 破发幅度

```python
ak.stock_ipo_summary_cninfo(symbol=code)   # 巨潮，字段「发行价格」
破发% = 最新价 / 发行价 - 1
```

**这一步最能区分真假**：2026-10 这批次新中位溢价 **+103%**，
即使从最高点跌 70%，相对发行价仍有 100%+ 浮盈 → 根本没套牢，只是挤泡沫。

### Step 6 · 缩量程度（"装死"的核心）

```python
初期换手%   = 上市后前 10 个交易日的平均换手率
近5日换手%  = 最近 5 个交易日平均换手率
换手萎缩比   = 近5日 / 初期
日均成交额   = 最近 5 日成交额均值（万元）
```

典型装死：萎缩比 < 0.15、近 5 日换手 < 3%、日均成交额 2,000~5,000 万。

### Step 7 · 组合画像

「深套 + 缩量 + 小盘」同时成立才算标的：

```
破发% < 0  ·  换手萎缩比 < 0.35  ·  流通市值 ≤ 30 亿
```

2026-10 全池 29 只里只有 **1 只**（惠康科技）完全符合——
说明真正进入"装死期"的次新很少，大多数还在挤泡沫。

## 1. 逻辑

次新股炒作退潮后会进入三个阶段：

```
炒作期（高换手）→ 装死期（缩量阴跌，抛压枯竭）→ 放量期（资金重新进场）
```

**装死期的特征**：换手率从初期 30%+ 萎缩到 2~3%，日均成交额降到几千万。
此时拉抬成本极低（几千万就能打出波动），是短炒资金的理想标的 —— 但**装死不等于会涨**，
必须等放量确认。

## 2. 判定口径

| 指标 | 计算 |
|---|---|
| 换手倍数 | 今日换手率 ÷ 前 20 日均换手率 |
| 距发行价% | 最新价 / 发行价 − 1（破发为负） |
| 距20日最高% | 最新价 / 近 20 日最高价 − 1 |
| 5日均成交额 | 近 5 日成交额均值（万元，衡量流动性枯竭程度） |

**状态分级**：

| 状态 | 条件 | 含义 |
|---|---|---|
| ★放量启动 | 换手倍数 ≥3 且 涨幅 ≥+3% | 资金进场，重点看 |
| ⚠放量下跌 | 换手倍数 ≥3 且 跌幅 ≤-3% | 抛压释放，短期别碰 |
| 放量观察 | 换手倍数 ≥2 | 有异动 |
| 正常 | 0.6 ≤ 倍数 < 2 | — |
| 装死中 | 倍数 < 0.6 | 抛压枯竭 |

## 6. 数据源与限制

- **日线**：BaoStock（`adjustflag=3` 不复权）。**东财 push2his 在本机被阻断，不要用 `ak.stock_zh_a_hist`。**
- **发行价**：`ak.stock_ipo_summary_cninfo`（巨潮），已在观察池 CSV 中固化为 `发行价` 列。
- **市值**：腾讯行情 `qt.gtimg.cn` 批量取（字段 44=流通市值亿、45=总市值亿）。

已知限制：

1. **不等同于买入信号** —— 装死只是"抛压枯竭"，可能长期阴跌。
2. **解禁压力** —— 次新 1 年后有大量限售股解禁，观察窗口要算清楚。
3. **样本小** —— 半年主板+创业板次新仅 29 只，统计意义有限。
4. **大多数次新仍在发行价上方**（2026-10 中位溢价 +103%），"深套"仅少数个股成立。
