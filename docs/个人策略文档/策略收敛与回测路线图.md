关联文档：《数据与验证统一约定》（唯一数据/评估口径）、《策略与脚本冻结登记》（去留登记）、《开源工具融合规划（investment_data-qlib-TradingAgents）》（数据底座与因子检验）、《个人策略修改记录》（留痕）。

## 0. 起点盘点（2026-09-26）

- 默认每日 4 条线：`earnings` / `hundred_day_high` / `daily_slow_rise` / `trend_leader`；`long_base_release` 已停用；8 条策略冻结中。
- ✅ 2026-09-27 更新：⑤ 判定后 `daily_slow_rise` 冻结并移出默认每日 → **当前默认 3 条线（earnings / hundred_day_high / trend_leader）**；冻结策略 8 → 9 条（详见《策略与脚本冻结登记》）。
- 已完成一轮统一口径评估（`data/strategy_review/leaderboard.md`），但存在 4 个口径缺口，导致"最优"结论还不够硬：
  1. **成本=0**：评估器已有 `--slippage-bps / --fee-bps / --turnover-penalty-bps` 三个参数，但历史评估全部按 0 跑；
  2. **可成交性未过滤**：涨停/一字板/停牌日按收盘价买入在实盘不可复现（评估器暂无该过滤）；
  3. **无复权数据**：`stock_daily` 无复权列，除权日收益失真（高分红股票尤甚）；
  4. **样本窗不齐**：`trend_leader` 只测 4/20~7/9（7 月后停用无快照）、`earnings` 到 7/10、`hundred_day_high` 到 9/25——各线考察期不同，不能直接比"最优"；且缺**基准**（沪深300）与**随机对照**。
- 可用基建（不重建）：PIT 重建（`data/runtime/pit_run.py`、`pit_rebuild.sh`，9/11~9/24 已实跑）、快照库 `kline_signal_snapshot`、统一评估器、复盘导出 `scripts/daily_review_export.py`、内置选股引擎（未启用）、investment_data / qlib 规划。

## 1. 总路线

四步闭环，顺序不可换：

```text
① 校准尺子（口径 v2） → ② 同窗口回测（全候选线） → ③ 按预设标准收敛（晋级/观察/冻结） → ④ 工具固化（复盘/决策日志/推送）
```

**反过拟合铁律**：③ 的判定标准必须在 ② 跑数之前写死（本文件 §4），跑完后不允许改标准挑结果。

## 4. 预设判定标准（跑数前写死）

晋级需**全部满足**：

1. 样本 ≥ 100（含 PIT 补齐样本；不足者一律"观察"）；
2. 成本后 w1 或 w3 均值 > 0，且另一个不为负；
3. 成本后 w3 分月胜率过半为正（≥50% 的月份为正）；
4. 相对沪深300 超额 > 0；
5. 阈值 ±20% 扰动下结论不翻转（参数敏感性）；
6. 高于随机基线 95 分位（高于随机中位不算数）。

淘汰（任一触发即进入冻结候选）：成本后 w3 均值 < -1%；或样本 ≥100 但分月胜率 < 1/3；或超额 < -2%。

**§4 口径操作化（2026-09-26 跑数前写死，判定前不再调整）**

§4-5 阈值扰动（本轮覆盖范围与口径）：
- hdh：`--new-high-window` 80 → 64 / 96（±20%，核心入选窗口；profile 与其余参数与 PIT 批次一致）；
- trend：`--scan-prefilter-min-change-pct-60d` 3.0 → 2.4 / 3.6（±20%，扫描前置阈值，PIT 批次实测生效：全市场约 5.6k → 扫描约 1.6k）；
- trend 模板/评分内部阈值（如 near_new_high×0.98、return_20d≥8.0 等）为选择器脚本内硬编码、不经 CLI 暴露，本轮不覆盖，列为后续可选深化；
- dsr / earnings 不做晋级向扰动（dsr 为淘汰候选，earnings 样本不足）；
- 判据：两档扰动下 §4 条目 1~4 的结论方向均不翻转；
- 执行与产物：`scripts/pit_rebuild_sensitivity_window.sh`（独立 `sens__` 前缀 signal_type，不覆盖正式快照）。

§4-6 随机 95 分位（口径）：
- 统计量：成本后 w3 等权样本均值（`avg_stock_return_after_cost_pct` 同源口径：`--entry-mode daily`、31bps 成本、entry 可成交过滤、基准 000300 仅作记录）；
- 随机对照：`random_baseline__<线>` 同窗快照；
- 分布构造：日块 bootstrap —— 以 `signal_date` 为单位有放回抽 D 天（D = 随机对照覆盖交易日数），拼接当轮全部完成样本取均值，重复 5,000 轮，固定种子 20260926；
- 判据：策略线 w3 均值 > 随机分布第 95 百分位 → 通过；同时记录策略值在随机分布中的经验分位（参考）；
- w1 同法记录（参考项，不改变判定）；
- 执行与产物：`scripts/check_random_percentile.py` → `data/verification/random_percentile_2026-08-04_2026-09-24.json`。
