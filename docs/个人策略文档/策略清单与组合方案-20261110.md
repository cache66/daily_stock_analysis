## 7. 三个组合方案（我的排序）

### 方案 A：极简单引擎（最省心，先用它验证）
```
择时：market_regime（defensive → 半仓以下）
选股：S10 缩量回踩（补回放验证）或 S12 swing_pick（底部抬升+相对强度）
过滤：硬排除（银行/保险/证券/建筑/基建/ST/次新/超大盘/低流动性）+ 距离 MA20 ≤8% + 20日超额 ≥5pp
风控：止损 ≤9%，持有 3–10 日，T+5 评估
验证：次日开盘入场 → track → 20 条前向后再看要不要留
```
适合：你现在"先跑起来、看到干净名单"的诉求。

### 方案 B：双引擎（我更推荐）
```
底仓（长期）：股息线（含息年化 +9.7%）+ 基金定投
波段（短线）：方案 A 的选股引擎
业绩过滤：S1 earnings_surprise 只做标签（命中加分，不单独出票）
板块：board_cycle_scan + ETF 份额流（周频）决定"这周看哪几个板块"
```
适合：你说的"长期靠业绩/板块/ETF/机构，短线靠日 K 波段"——两套钱分开管。

### 方案 C：事件驱动（财报窗口专用）
```
S1 earnings_surprise + S-低位业绩观察（B 态正期望）+ 财报日历驱动
只在财报季/预告密集期跑，其余时间空仓
```
适合：你更信"业绩驱动"，但需要接受事件密度不稳定。
